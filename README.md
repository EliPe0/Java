# ☕ Estudos em Java

Repositório criado para armazenar meus exercícios, anotações e testes práticos durante meus estudos em Java.

A ideia é acompanhar minha evolução na linguagem, praticar lógica de programação e compartilhar meu aprendizado publicamente no GitHub 🚀

---

## 📚 Conteúdo do Repositório

### 📂 `saida_dados`

Exercícios focados em:

* Saída de dados
* `System.out.println`
* `printf`
* Formatação de números
* Uso de `Locale`

---

### 📂 `ent_dados`

Prática de entrada de dados utilizando:

* `Scanner`
* Leitura de:

  * Strings
  * Inteiros
  * Double
  * Linhas completas

---

### 📂 `teste_process`

Exercícios sobre:

* Processamento de dados
* Operações matemáticas
* Conversão de tipos
* Expressões aritméticas

---

### 📂 `func_mat`

Estudos sobre funções matemáticas da linguagem Java:

* `Math.sqrt()`
* `Math.pow()`
* `Math.abs()`
* Operações matemáticas básicas

---

### 📂 `exec_01`

Primeiros exercícios de fixação envolvendo:

* Variáveis
* Tipos primitivos
* Impressão formatada
* Estrutura básica de um programa Java

---

### 📂 `exec_02`

Lista de exercícios envolvendo:

* Soma de valores
* Área de círculo
* Diferença de produtos
* Cálculo de salário
* Cálculo de peças
* Fórmulas geométricas
